Nursery School Management System (WinForms)
Overview

This project is a small Nursery School Management System developed using C# WinForms and SQL Server.
The application helps nursery schools manage student information, teachers, classrooms, tuition fees, and daily activities through a simple desktop interface.

The system is designed for educational purposes and small-scale school management.

Features
Student Management
Add, edit, delete student information
Search students by name or class
Store parent contact information
Track attendance records
Teacher Management
Manage teacher profiles
Assign teachers to classrooms
Store teaching schedules
Classroom Management
Create and manage classrooms
Assign students to classes
Monitor classroom capacity
Tuition Management
Manage tuition fees
Payment status tracking
Monthly payment reports
Reports
Student list reports
Attendance reports
Tuition payment reports
